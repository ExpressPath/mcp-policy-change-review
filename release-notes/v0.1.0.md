# MCP Policy Change Review v0.1.0

First public pre-release of MCP Policy Change Review.

- Replays shared authorization scenarios across separate local OPA and Cedar policy planes.
- Reviews MCP tool inventory changes and policy decision differences, with a GitHub step summary.
- Synthetic local checks passed with OPA 1.22.0 and Cedar CLI 4.14.1.

Limitations: no customer-repository or GitHub-hosted-runner validation, no independent security review, no customer validation, and no production enforcement or security guarantee. Workflow owners install and pin their own policy-engine binaries. See `README.md`, `EULA.md`, and `PRIVACY.md`.
