# MCP Policy Change Review v0.1.2

Add an optional machine-readable JSON evidence report for GitHub Actions workflows.

- Set `report-file` to write the full review report to a new file inside `GITHUB_WORKSPACE` when all policy-plane executions complete, while preserving the existing job summary.
- Read the generated path from the `report-path` output and choose whether to upload it under your repository's own retention and access controls.
- The Action rejects paths outside the workspace, existing targets, symlinks, and paths whose parent directory does not exist; it never overwrites workspace content.
- The evidence fingerprint remains unsigned and does not authenticate approval, authorship, or provenance.

The synthetic release smoke checks that both a passing review and an intentionally failing drift review produce valid JSON reports. This is synthetic workflow validation only; it is not customer validation, an independent security review, or a production guarantee.
